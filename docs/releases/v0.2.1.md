# LocalBridge MCP v0.2.1

LocalBridge MCP v0.2.1 is a license patch release.

## Changed

- Changes the main LocalBridge MCP project license from MIT to Apache License 2.0.
- Updates package metadata, README badges, and documentation references to Apache-2.0.
- Keeps required upstream MIT attribution for selected Desktop Commander MCP-derived execution-core routines in THIRD_PARTY_NOTICES.md.

## Compatibility

No runtime, MCP tool, setup, tunnel, or macOS service behavior changed in this release.

## Notes

- v0.2.0 remains the original MIT-tagged source release artifact.
- v0.2.1 is the first Apache-2.0-tagged source release.
- Third-party MIT notices remain preserved as required provenance.
