# LocalBridge MCP v0.2.0

LocalBridge MCP v0.2.0 is the first product-polished source release after the full construction qualification matrix closed.

## Highlights

- Replaces the generic MCP tool surface with a LocalBridge-specific `lb_*` tool family.
- Renames MCP arguments to product-owned names such as `file_path`, `line_count`, `search_root`, `query_text`, `process_id`, and `stdin_text`.
- Moves construction and qualification evidence into `docs/qualification/` so public docs read as product documentation instead of phase handoff material.
- Promotes test scripts from phase-number names to product-level names: `test:core`, `test:mcp`, `test:policy`, `test:runtime`, `test:public`, `test:release`, `test:lifecycle`, and `test:final`.
- Preserves source-only release, fail-closed configuration, macOS Runtime.app/TCC behavior, launchd supervision, active-only sleep prevention, and OpenAI Secure MCP Tunnel deployment.

## Breaking changes from v0.1.0 release candidates

The MCP tool names and tool arguments changed intentionally. Existing local MCP client registrations should rediscover the server before use.

Examples:

- `read_file` -> `lb_read_text`
- `write_file` -> `lb_write_text`
- `edit_block` -> `lb_patch_text_block`
- `start_search` -> `lb_search_start`
- `start_process` -> `lb_run_shell`
- `read_process_output` -> `lb_shell_output`

## Security model

LocalBridge MCP is intentionally privileged. Filesystem allowlists and command blocklists are guardrails, not an operating-system sandbox. Shell commands run with the permissions of the account that launches LocalBridge MCP.

Do not expose an unauthenticated shell-capable MCP endpoint to the public Internet.

## Known boundaries

- Windows is not yet qualified.
- Linux production service management is not yet implemented.
- No hosted relay or shared credentials are provided.
- npm publication is disabled.
- The macOS Runtime.app is created locally and is not distributed as a notarized binary.
- Active-only macOS no-sleep behavior is qualified for the local production tunnel lifecycle, not for display wake, lid-close override, or non-macOS service management.
